# desmos-cl-formatter README

This extension formats Desmos construction layer code into a more human-readable format and provides IntelliSense to speed writing.

## Features

- Autoformats code to prioritize nesting and shorter lines where logically possible.
- Provides IntelliSense to make coding faster.

## Requirements

Will autoformat both unsaved files and files with the extension *.desmos.

## Known Issues

Beta version, nothing known but also untested.
